# MLWEC Connect 🎓

A modern and responsive college website concept for **Malineni Lakshmaiah Women's Engineering College**.

## 🚀 About the Project

MLWEC Connect is designed as a simple digital gateway for students, parents, and visitors to explore college information in an organized and user-friendly way.

The website brings important sections together in one place, including:

* 🎓 About the College
* 💻 Engineering Programs
* 🏫 Campus Facilities
* 📢 Admissions
* 💼 Training & Placements
* 🎉 Campus Activities
* 📩 Contact Section

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Responsive Web Design

## ✨ Key Features

* Modern landing page
* Responsive design for mobile and desktop
* Interactive navigation menu
* Animated statistics
* Smooth scrolling
* Admission interaction
* Contact form interaction
* Back-to-top button
* Single-file architecture

## 🎯 Project Goal

The goal of this project is to create a clean and accessible digital presence for a women's engineering college while giving students a simple way to explore academic programs, campus facilities, admissions, and career opportunities.
